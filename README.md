# Print-Even-Numbers

The Scenario:
You are programming a robotic arm for a manufacturing plant. A conveyor belt is passing exactly 15 items in front of the robot, numbered 1 through 15.

The factory manager has a strict rule: The robot must only pick up and pack the Even-numbered items. It must completely ignore the odd-numbered items.

The Goal:
You need to write a C++ program that loops through the numbers 1 to 15. For every number, the computer needs to make a decision: If the number is even, print "Item [number] Packed!".
